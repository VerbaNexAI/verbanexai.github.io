## 🧪 About VerbaNexAI Lab

**VerbaNexAI** is a research laboratory at the [Universidad Tecnológica de Bolívar (UTB)](https://www.utb.edu.co), Cartagena, Colombia. We explore the convergence of **Natural Language Processing**, **Artificial Intelligence**, and **computational linguistics** to build solutions for multilingual and low-resource environments.

> *"Verba"* (words) + *"Nex"* (connection) + *"AI"* — connecting language and intelligence.

🌐 **Website:** [verbanexai.github.io](https://verbanexai.github.io)

---

## 🔬 Research Lines

| Line | Focus |
|------|-------|
| 🗣️ **Natural Language Processing** | Semantic comprehension, sentiment analysis, text analytics, phonesthemes |
| 🤖 **Applied AI Models** | Forecasting, machine learning, intelligent frameworks |
| 🏆 **Shared Tasks** | IberLEF, SemEval, CLEF — multilingual NLP benchmarks |
| 👁️ **Computer Vision** | Deep learning for microscopy, object detection (YOLO), agricultural imaging |
| 📊 **Data Representation** | Knowledge graphs, neural information retrieval, embeddings |

## 🌐 Website — Local Development

This site is built with [Jekyll](https://jekyllrb.com/) using the [al-folio](https://github.com/alshedivat/al-folio) theme.

### Prerequisites
```bash
ruby >= 3.0
bundler
jekyll
```

### Run locally
```bash
git clone https://github.com/VerbaNexAI/verbanexai.github.io.git
cd verbanexai.github.io
bundle install
bundle exec jekyll serve
```

Open `http://localhost:4000` in your browser.

### Run with Docker
```bash
docker-compose up
```
